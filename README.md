### About

I design and build business solutions on the Microsoft cloud — from low-code apps that ship in days to pro-code platforms that run at enterprise scale. I work across the whole stack: data model, integrations, backend, frontend, ALM and deployment.

Lately I focus on bringing **AI into real business workflows** — multi-agent systems, LLM-powered automation and developer tooling built on Claude and OpenAI models.

### What I build

- **Business apps on Power Platform & Dynamics 365** — model-driven and canvas apps, Dataverse data models, plugins, PCF controls, Power Automate flows
- **ERP integrations** — Business Central APIs and extensions, web portals connected to ERP data
- **SharePoint & Microsoft 365 solutions** — SPFx web parts and extensions, Microsoft Graph integrations, migrations
- **Cloud backends on Azure** — Azure Functions, APIs, identity with Entra ID, serverless integrations
- **Custom web apps & e-commerce** — React / Next.js frontends, Node.js backends, headless CMS, PWAs
- **AI solutions** — multi-agent orchestration, LLM integration into existing systems, AI coding tooling and plugins
- **ALM & DevOps** — solution lifecycle automation, CI/CD pipelines, environment strategy for Power Platform
